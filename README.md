Repurposed from Chem Kings for Pappas Pools. 18 server-rendered pages, responsive navigation, local SEO, structured business data, sitemap and new social preview.

Run npm run build, npm test, npm run validate. Source: worker/site.js and worker/handler.js. Assets are embedded via assets-data.json.

Quote requests are saved to R2 under pappas-inquiries/, separate from the previous business. /admin/ requires the existing INBOX_KEY. Requests do not send email notifications. Phone and email links contact Pappas directly. Confirm lead delivery arrangements before business handoff.

The navy and turquoise wave logo is a custom concept mark. Pool photograph is illustrative stock imagery. The footer identifies this as a concept awaiting business approval.

GitHub repository retains its original chem-kings-pool-service name for continuity; contents now represent Pappas Pools. Sites source repository is authoritative for deployment.
